# Архив исходной инфраструктуры

Эта папка хранит код и SQL прежней инфраструктуры только для аудита и восстановления истории миграции.

- Production runtime, сборка, тесты и deployment не импортируют файлы из этой папки.
- Канонический идентификатор пользователя остался `public.users.id`; миграция авторизации не меняет UUID.
- Ссылки на прежнее хранилище в Yandex PostgreSQL были проверены после переноса media: остаток равен нулю.
- Удалять архив можно отдельно после завершения организационного срока хранения.

Новая схема авторизации находится в `yc-functions/migrations/003_quizflow_auth.sql`, а runtime — в `yc-functions/api-auth` и `yc-functions/_shared`.
