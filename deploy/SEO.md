# Индексация Потока

Основной адрес: https://mykviz.ru/. Дополнительный домен mykviz.online
сохраняется; canonical указывает на mykviz.ru.

## Сборка и проверка

`npm run build` создаёт главную с текстом до запуска JavaScript, три самостоятельных
HTML-руководства и sitemap из `seo/content.ts`. Те же вводные материалы и ссылки
видны на React-лендинге. Hash-маршруты приложения не включаются в sitemap:
это не отдельные серверные страницы. Публичные квизы и кабинет работают как раньше.

`npm run check:seo` проверяет собранные файлы.
`npm run check:seo -- https://mykviz.ru` проверяет HTTPS, HTTP-статусы,
типы ответов, canonical, sitemap и наличие текста без JavaScript через CDN.
Деплой выполняет эту проверку после очистки кэша.

## Выбор Яндекс-версии вместо Vercel

После успешной проверки mykviz.ru на действующей Vercel-версии нужен
canonical на https://mykviz.ru/ для дублирующей главной. Не перенаправляйте
все квизы и личные кабинеты между разными базами данных без проверки совместимости.
Не закрывайте старую главную в robots.txt: робот должен прочитать canonical.

В Яндекс Вебмастере добавьте https://mykviz.ru/sitemap.xml и отправьте главную
и руководства на переобход. При полном переносе сайта используйте инструмент
«Переезд сайта». В Google Search Console отправьте sitemap и запросите проверку
главной. Эти действия требуют доступа владельца к соответствующим панелям.

Canonical — сигнал для выбора основной страницы, а не гарантия результата.
Индексация и позиции зависят от поисковой системы и обновляются после обхода.
Не добавляйте страницы-дубли под каждый вариант ключевой фразы.
